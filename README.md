# 家庭分享計時（`family-timer`）

方便小組「家長、副家長」帶分享時使用的純靜態離線計時小程式（PWA）。
支援從**排組雷達**一鍵帶入小組名單，或現場手動輸入、一次貼上多個名字、拍照紙本名單本機 OCR 自動填入。

> 致謝：計時核心與 iOS 音訊防休眠機制延伸改版自原創專案 `dichiwu/share-timer`。本專案獨立部署於 `https://juliatsai.github.io/family-timer/`，不影響原創專案。

---

## 核心設計原則（支援 100+ 組同時開啟、零伺服器）

1. **完全無後端、資料不出裝置**：
   - 沒有資料庫與 API。所有組別名單、座位性別、時間設定與已分享紀錄 100% 只存在該台裝置自己的 `localStorage`（鍵值：`familyTimer.v2`）。
2. **靜態網頁 ＋ Service Worker 全離線快取**：
   - 100 組同時點開連結時，僅各自從靜態 CDN 下載一次頁面與子集字型，之後由 `service-worker.js` 接手**完全離線運作**，不會塞車或互相干擾。
3. **自帶跨平台一致字型**：
   - 內建裁切後的 `Noto Sans TC`（400～600 字重，涵蓋繁中常用字與台灣人名罕見字 `.woff2`）與 `Inter` 數字字型，Windows、iPad、iPhone 顯示完全一致。
4. **首次開啟零假資料**：
   - 初次打開且本機尚無名單時，直接進入「**名單設定**」畫面，不產生假人名或錯誤畫面。
5. **多組別獨立存檔**：
   - 以「`課程名稱` ＋ `家庭 / 組別`」區分不同組別，可在設定中隨時切換或新增另一組，各存各的進度。

## 兩種開啟流程

### 1. 從「排組雷達」一鍵開啟或複製連結
- 排組雷達透過 URL Hash（`#g=<Base64URL>`）傳遞 `{ 課程名稱, 家庭/組別, 成員與角色性別 }`（`#` 內容不會傳送至伺服器）。
- 自動對位規則：
  - **名單設定輸入順序**：**第 1 格永遠是家長**、**第 2 格永遠是副家長**，大堂課預設 **第 3 格標示 `小天使{}`**、**第 4 格標示 `小天使{}.`**（`{}` 自動隨家庭編號連動，如 `小天使16`、`小天使16.`；進階課無小天使時自動隱藏），第 `5～12` 格為組員；第 `3～12` 格皆支援拖曳手把調整順序，且小天使角色標籤會跟著人一起移動。
  - **桌次座位模式（有桌椅）**：**家長固定在正下方中央**、**副家長固定在正上方中央**鎖定不變；其餘 10 個組員座位支援直接在圓桌畫面上**拖曳換座位**（亦可點「排座位」顯示空位自由對調，`小天使{}`／`小天使{}.` 標籤隨人移動）。
  - **序號／就地圍圈模式（未輸入姓名或活動結束圍圈）**：若名單設定未輸入任何姓名直接點開始，或頂端切換至「**序號 / 圍圈**」，會以 `1、2、3 …` 序號或**家長為中心起點**切換**順時針／逆時針**，支援一鍵「下一位」連續計時。
- 載入後會清除網址尾巴並先停在「**名單設定**」畫面，讓家長確認或微調座位後按「**完成，開始分享**」。

### 2. 一般連結開啟（手動輸入／一次貼上／紙本拍照 OCR）
- **手動輸入**：填寫「課程名稱」（如 `2-50`）、「家庭 / 組別」（如 `第 16 家庭`）與 12 個座位姓名及 `♀ / ♂` 切換。
- **一次貼上多個名字**：每行一個名字（亦支援貼上含「家長／副家長」、「男／女」或編號之文字，自動智慧解析對位）。
- **拍照辨識紙本名單（本機離線 OCR）**：
  - 拍下現場紙本印出來的名單後，可用綠色裁切框只框選「姓名欄（或執事＋姓名欄）」，自動執行灰階去陰影強化，並於瀏覽器本機端執行 Tesseract.js (`chi_tra`) 辨識填入（照片不離開裝置；OCR 字庫僅在首次點選辨識時按需下載並快取）。

## 畫面與計時規則

- **圓桌 12 座位（順時針）**：
  - 上排（左→右）：`1`、`2 [副家長]`、`3`
  - 右排（上→下）：`4`、`5`、`6`
  - 下排（右→左）：`7`、`8 [家長]`、`9`
  - 左排（下→上）：`10`、`11`、`12`
  - 空白未填姓名的座位自動隱藏，中央進度圓點與 `已分享 X / N` 僅計算實際人數。
- **語音與鈴聲提示**：
  - 剩餘 20 秒：語音「剩下 20 秒」（音量 0.6）＋ 暖橘呼吸描邊
  - 00:00 時間到：Web Audio 雙音叮咚 ＋ 語音「時間到」（音量 1.0）
  - 超時階段：靜音累計 `+mm:ss`，整頁轉暖紅柔光提醒，描邊依設定之「超時緩衝時間」（預設 30 秒，可調 30秒／1分／2分／3分）順時針繞滿一圈。

## 目錄結構

```text
index.html              主頁面（名單設定頁 ＋ 計時主畫面 ＋ 抽屜與彈窗）
manifest.json           PWA 安裝設定
service-worker.js       離線預快取與 OCR 按需快取
fonts/                  自帶離線字型（Inter + Noto Sans TC 常用字與人名子集 .woff2）
icons/                  PWA 圖示
styles/
  fonts.css             @font-face 宣告
  tokens.css            莫蘭迪淺色／深色／超時色彩變數與共用按鈕
  setup.css             名單設定雙欄 12 座位樣式
  timer.css             計時主畫面與圓角方框盤面樣式
  seats.css             四周 12 座位環桌樣式（含正副家長與小天使角色標籤）
  circle.css            序號／就地圍圈模式樣式
  panels.css            設定抽屜、時間調整器與成員清單卡片
  modals.css            一次貼上與紙本 OCR 拉框彈窗樣式
  mobile.css            手機窄螢幕專屬響應式樣式
js/
  main.js               應用入口、Hash 匯入、路由切換與快捷鍵
  icons.js              全站 SVG 圖示產生器
  codec.js              URL Hash Base64URL 解碼與貼上／OCR 智慧解析
  store.js              localStorage 多組別獨立儲存管理
  audio.js              Web Audio 叮咚合成、Web Speech 語音與螢幕防休眠
  timer-engine.js       系統時間差倒數狀態機
  setup-view.js         名單設定畫面互動
  seat-drag.js          圓桌組員座位長按／拖曳換位控制器
  seat-renderer.js      四周圓桌座位與清單卡片渲染器
  circle-view.js        序號／就地圍圈模式控制器
  timer-view.js         計時主畫面整合控制器
  drawer-view.js        設定抽屜與組別切換互動
  ocr.js                紙本拍照裁切、去陰影強化與 Tesseract.js 本機辨識
```
